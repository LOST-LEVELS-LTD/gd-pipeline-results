# gd-pipeline-results

Документация результатов ИИ-конвейера **gd-pipeline** (поиск и проверка идей игр
«в духе Ticket to Ride» с роглайт-механиками) — статический сайт.

**Сайт:** https://lost-levels-ltd.github.io/gd-pipeline-results/

## Что выложено

- **Прогон №4 «Простой язык»** — «Литерный состав» (GO, приоритет), «Магистраль-коридор» (GO с условиями), «Страна вокруг рельсов» (REWORK).
- **Прогон №3 «Новые территории»** — первый прогон без REWORK: «Совет директоров», «Полоса отчуждения», «Чугунка».
- **Фаза «Игрок»** — симуляционная проверка «Литерного состава»: саммари, свод правил сцены, сид-лог, 4 протокола партий (эксплойтер/казуал + дубли), вердикт фазы.

## Структура

- `content/` — исходные markdown-артефакты прогонов (как есть, без ретуши).
- `templates/` — рукописные страницы (обзор, саммари фазы «Игрок») с маркером `@@SIDENAV@@`.
- `docs/` — собранный сайт (GitHub Pages, ветка `main`, папка `/docs`); на каждой странице — боковая навигация с подсветкой текущего документа.
- `build.py` — генератор: markdown → страницы-документы, подстановка навигации в шаблоны.

Пересборка: `pip install markdown && python build.py`.
