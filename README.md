# gd-pipeline-results — ГД-архив Lost Levels

Публикация лучших прогонов ИИ-конвейера **gd-pipeline** (поиск и проверка идей игр
«в духе Ticket to Ride» с роглайт-механиками) в виде статического сайта.

**Сайт:** https://lost-levels-ltd.github.io/gd-pipeline-results/

## Что выложено

- **Прогон №4 «Простой язык»** — «Литерный состав» (GO, приоритет), «Магистраль-коридор» (GO с условиями), «Страна вокруг рельсов» (REWORK).
- **Прогон №3 «Новые территории»** — первый прогон без REWORK: «Совет директоров», «Полоса отчуждения», «Чугунка».
- **Раздел агента-игрока** — пилот симуляционного плейтеста «Литерного состава»: свод правил сцены, сид-лог, 4 протокола партий (эксплойтер/казуал + дубли), вердикт фазы и краткое саммари.

## Структура

- `content/` — исходные markdown-артефакты прогонов (как есть, без ретуши).
- `docs/` — собранный сайт (GitHub Pages, ветка `main`, папка `/docs`).
- `build.py` — генератор страниц-документов из `content/` (python-markdown); `docs/index.html` и `docs/player/index.html` написаны руками.

Пересборка: `pip install markdown && python build.py`.
