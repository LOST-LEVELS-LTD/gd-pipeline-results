Документация результатов

ГД-конвейер gd-pipeline

gd-pipeline — экспериментальный конвейер из ИИ-агентов, который ищет и проверяет идеи игр. Тестовая задача: одиночная премиум-игра «в духе Ticket to Ride» с роглайт-механиками. Здесь опубликованы два лучших прогона целиком — от брифа до вердиктов, без правок задним числом.

Как устроен конвейер

Пять ролей с разными зонами ответственности; каждая фаза оставляет отдельный документ:

  • 01 Генератор — ширина
  • 02 Концептер — карточки
  • 03 Критик — глубина
  • 04 Игрок — симуляция
  • 05 Синтез — gate

Генератор выдаёт 20 разнообразных идей по заданным «линзам» (механики проверенных рынком игр). Оркестратор отбирает 3 кандидата, концептер разворачивает каждого в карточку — описание игры языком рядового игрока. Критик разбирает карточку на прочность: оценки 0–3 по аспектам, находки с контраргументами. Игрок — симуляционная проверка: агент играет формализованную сцену концепта и меряет её метриками. Синтез сводит всё в отчёт с жёстким правилом: ноль в фундаменте не компенсируется ничем.

Как читать документацию

Каждый прогон — папка из документов в порядке работы конвейера: бриф (задание) → пул идей → отбор кандидатов → концепт-карточки A/B/C → вердикты критика A/B/C → итоговый отчёт. Быстрый способ понять прогон — начать с итогового отчёта: он открывается блоком «Что за игра» по каждому кандидату и сводной таблицей оценок. Карточки и вердикты — для погружения в детали.

Статусы кандидатов: GO — фундамент цел, можно углублять; GO с условиями — цел, но следующий шаг предписан; REWORK — найден блокер уровня ядра, нужна переработка до любой дальнейшей работы.

Прогоны

Прогон №4 — «Простой язык»

Бриф: механики Ticket to Ride + роглайт; линзы — Slay the Spire, Vampire Survivors, Monster Train, Loop Hero, Against the Storm. Впервые в конвейере: описания языком рядового игрока и пилот фазы «Игрок». 20 идей → 3 кандидата → 3 вердикта.

  • B «Литерный состав»Monster TrainGO · приоритет

    Защити поезд, который не остановится. Лучший фундамент прогона; главная проблема — обходимое правило налётов. Прошёл симуляционную проверку фазой «Игрок».

  • A «Магистраль-коридор»Slay the SpireGO с условиями

    Дорога только вперёд: развилки закрываются навсегда, уголь тает. Условие — бумажный прототип микропетли до дальнейшей деталировки.

  • C «Страна вокруг рельсов»Loop HeroREWORK

    Поезд наматывает круги, игрок строит страну вокруг. Пробит блокер вычислимости: партия решается заранее, напряжение умирает.

Прогон №3 — «Новые территории»

Бриф: премиум-роглайт на механиках Ticket to Ride; линзы — Balatro, Hades, FTL / Into the Breach, Dead Cells, Darkest Dungeon. Первый прогон конвейера без единого REWORK.

  • A «Совет директоров»BalatroGO

    Сеть — счётный движок «база × множители», обязанный раз в квартал пробивать растущий аппетит совета. Самый готовый к проверке матмоделью.

  • B «Полоса отчуждения»FTL / Into the BreachGO

    Вместо живого соперника — диверсанты с ударами, объявленными на ход вперёд: их не отменяешь, а переводишь и жертвуешь.

  • C «Чугунка»Darkest DungeonGO на волоске

    Рельсы кладут живые артели — и ломаются раньше рельсов. Сильный питч, спорная фирменная механика сметы.

Фаза «Игрок» — симуляционная проверка

Отдельный раздел документации. Концепт-карточка формализуется в свод правил одной сцены, случайность фиксируется сид-логом, и две контрастные персоны — «эксплойтер» и «казуал» — играют партию ход за ходом. Выход — не мнение, а проверяемые метрики: плотность решений, автопилот, реальность угрозы поражения, петли, дыры правил. Пилот проведён на «Литерном составе»; каждая персона сыграла по две независимые партии.

  • 4партии × 17–18 ходов
  • 41 = 41счёт двух эксплойтеров
  • 8найденных эксплойтов
  • 4/4предсказаний критика подтверждено
